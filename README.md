# Atividade 01 formulario banda

Projeto Criado com o intuito de poder cadastrar bandas onde registramos o tipo de musica, membros, informações dos membros.

 Getting Started

   Projeto criado utilizando a ferramenta FlutterFlow, onde iniciamos pela pagina inicial de login
